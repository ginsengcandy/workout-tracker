# Levio Roadmap

> 운동을 의지의 문제가 아니라, 가벼운 일상의 흐름으로.

## 현재 진행 순서

### 1. 모바일 시간 박스 겹침 픽스
- **상태**: 다음 작업
- **사이즈**: S (1 커밋)
- 입력 탭의 시작/종료 시간 input이 narrow viewport에서 겹치는 UX 버그
- 1차 후보: `S.row` 안의 flex 자식에 `minWidth: 0` 추가

### 2. 헤더 로고 교체
- **상태**: 로고 에셋 대기 중 (Levio 워드마크)
- **사이즈**: S (1 커밋)
- 헤더의 "운동 기록" 텍스트를 Levio 워드마크 이미지로 교체
- `💪` 이모지 정리 여부 결정 필요

### 3. 로딩 스크린 + 명언
- **상태**: 대기
- **사이즈**: M (1-2 커밋)
- 현재의 "불러오는 중..." 텍스트를 로고 + 페이드인 + 명언 한 줄로 교체
- 명언 풀은 brand-concept.md의 슬로건에서 시작
- 노출 시간 2초 내외

### 4. 부위별 인체 도식 히트맵
- **상태**: 대기 (방향 확정됨)
- **사이즈**: L (2-3 커밋)
- 인체 실루엣 SVG + 부위별 볼륨/빈도에 따른 색 진하기
- Bauhaus 기하학 비주얼과 결 맞추기
- 통계 탭에 추가
- Recharts가 아닌 커스텀 SVG 작업

### 5. 백엔드 + credential 기반 데이터
- **상태**: 대기 (스택 미정)
- **사이즈**: XL (멀티 위크)
- localStorage → 원격 저장소 전환
- 필요한 결정:
    - 백엔드 스택 (Supabase / Firebase / 직접 구축)
    - 인증 방식 (이메일·비번 / OAuth)
    - localStorage 데이터 마이그레이션 전략 (`wk_v1` → 원격 + `wk_v2`)
- `persist`가 이미 async 시그니처라 호출부 수정 없이 구현 교체 가능 (`decisions.md` #10)

---

## 장기 고민 (Long-term)

### 퀘스트 + 보상 시스템
- 일반적인 게이미피케이션(XP, 레벨, 스트릭 압박, 배지)은 Levio 브랜드와 충돌
- 브랜드 결에 맞는 방향성 후보:
    - 압박 없는 데일리 체크인 ("오늘도 움직였는가")
    - 미적/조용한 보상 (색조·패턴 변화, 아이콘 진화 등)
    - 경쟁·스트릭 압박 없음
    - "계속하게 만드는" 메커니즘 중심
- 코드 작업 전 디자인 세션 필요
